# Contribution Guidelines

Thank you for contributing.

## Branching
- Always create a feature or bugfix branch
- Do not raise PRs from main branch

## Pull Requests
- Keep changes **minimal and scoped**
- Avoid large/bulk changes in a single PR
- Each PR should address **one logical change only**

## Artifacts
- Do not commit generated files (artifacts/)
- These are runtime outputs and should remain local

## Review
- PR must include:
  - Change summary
  - Reason for change
  - Impact analysis
  - Test results

PRs not following these guidelines may be rejected or requested for rework.
